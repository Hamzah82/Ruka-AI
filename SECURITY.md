# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest  | ✅ |

## Reporting a Vulnerability

If you discover a security vulnerability, please open an issue with the "security" label.

## Setup Credentials

1. Copy `.env.example` to `.env` and fill in your own API keys
2. Copy `SKILL/config/email/msmtprc.example` to `SKILL/config/email/msmtprc` and fill in your Gmail App Password
3. Copy `users.json.example` to `users.json` and fill in your collaborators

**NEVER commit real credentials to the repository.**
